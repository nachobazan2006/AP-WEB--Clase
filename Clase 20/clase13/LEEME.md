# Clase 20: JSON y asincronía

## Qué aprendés

`fetch` obtiene un archivo JSON local. `async/await` espera la respuesta; el catálogo muestra estados de carga y error. Necesita un servidor local.

## Cómo probar

Desde esta carpeta ejecutá `npx five-server src` y abrí `catalogo.html` en el navegador. Usá un servidor: los módulos, `fetch` y los archivos locales no funcionan de forma confiable con `file://`.

## Para practicar

Cambiá temporalmente la ruta del JSON y observá el mensaje de error.
