# Clase 21: Persistencia local

## Qué aprendés

`localStorage` guarda los ID de productos seleccionados. Al recargar, la página recupera la selección y actualiza el contador. Si el almacenamiento está bloqueado, el catálogo sigue funcionando.

## Cómo probar

Desde esta carpeta ejecutá `npx five-server src` y abrí `catalogo.html` en el navegador. Usá un servidor: los módulos, `fetch` y los archivos locales no funcionan de forma confiable con `file://`.

## Para practicar

Guardá dos productos, recargá la página y comprobá que el contador se conserva.
